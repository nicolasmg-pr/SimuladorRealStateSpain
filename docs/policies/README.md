# Policy evidence files

One file per policy lever (../plan.md Phase 3). Fixed structure:

1. **Mechanism** — what the lever changes, mechanically, and who holds it (state / CCAA / municipal).
2. **Evidence for** — studies finding the intended effect, with effect sizes.
3. **Evidence against / side effects** — studies finding null, adverse, or substitution effects.
4. **Effect-size range** — the span the model must be able to reproduce.
5. **Model mapping** — which `scenario.Intervention` parameters implement it.

Both sides always. A lever file with evidence in only one direction is incomplete, not settled.
