# Actor dossiers

One dossier per market actor. The model's behaviour rules are derived from these files
and only from these files — a rule with no dossier row behind it is a guess and is
labeled as one.

Rules (from ../plan.md):
- Every claim cites ≥2 independent sources, registered in ../sources.md.
- Disagreement between sources is recorded, not resolved: the parameter becomes a range.
- Tier-2 (interpretive) sources never stand alone.

Template (fixed — keep section order):
1. Role & size in the market
2. Balance sheet & constraints
3. Observed decision rules (with evidence)
4. Reaction to past shocks (case episodes)
5. Power & relations to other actors
6. Extracted parameters (value or range + sources)
7. Open questions
