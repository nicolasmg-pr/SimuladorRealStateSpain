# Pre-registration: the sealed 2008–2013 hold-out

This is the one that cannot be re-run. It is the single out-of-sample test of the whole
model, and re-fitting anything after it has been run destroys it as evidence
(`model-spec.md §13.4`, `docs/holdout-2008-2013.md`). Committed **before** the run; the git
history is what makes that verifiable.

- **Date:** 2026-09-14
- **Commit hash:** filled in by the commit that adds this file — the run follows it
- **Scenario:** `resim.holdout.scenario()`, 24 ticks = 2008Q1 … 2013Q4, tick 0 initialised at
  **2007Q4** conditions
- **Seeds:** 10 (the post-phase-E minimum, `model-spec.md §13.4`)
- **Ticks:** 24
- **Parameters swept:** none. Every free parameter is at the value the calibration window
  (2014–2025) produced, and none is touched afterwards.

## Inputs, each a registered series

| Input | Series | Value at the start → at the end |
|---|---|---|
| Euríbor 12m | BdE Boletín Estadístico 19.1 (`D_1NBAF472`) | 4.68% (2007Q4) → 5.37% peak (2008Q3) → 0.51% (2013Q2) |
| Household joblessness | INE EPA tabla 65276, "todos los activos parados" | 3.61% (2007Q4) → **15.02%** (2013Q1) |
| Household formation | INE EPA tabla 65269, Q4 to Q4 | 474k/yr (2007) → 387k (2008) → **91k** (2013) |
| Completions in the pipeline | MIVAU Boletín Online tabla 3.2 | 563,631 (2008) → **43,230** (2013) |
| Credit standards | BdE Encuesta sobre Préstamos Bancarios | tightening from 2008Q3: LTV −15pp, DSTI −5pp, spread +1.5pp |
| Foreclosure regime | LEC art. 693 as amended by Ley 1/2013 | three unpaid instalments, not today's twelve |

Nothing else is set. In particular the model's own parameters — the expectation gain, the
search breadth, the reserve rule, the insolvency chain — are exactly what phases B, C and D
left, identified on 2014–2025 moments.

## Predicted direction, before running

| Quantity | Prediction | Mechanism that would produce it |
|---|---|---|
| National price, peak to trough | **−30% … −45%** | expectations turn negative and feed the valuation anchor (§5c.1); the credit screen cuts budgets; forced supply arrives from arrears and repossession |
| Transactions, end vs start | **−40% … −85%** | credit screen plus the seller's reserve: an owner in negative equity cannot convey clear title, so volume collapses before price does (§5c.3) |
| Arrears, peak share of mortgaged | **4% … 9%** | joblessness ×4 with a benefit capped at 175% of IPREM; the BdE doubtful ratio peaked at 6.28% in 2014Q1 |
| Foreclosure flow, peak per year | **0.7% … 2.0%** of mortgages | the three-instalment regime triggers a year earlier than today's law; CGPJ filed 93,636 in 2010 ≈ 1.4% of the 6.46M mortgages outstanding |
| Bank REO stock | **> 0, building** | possession transfers dwellings to the bank, which releases them slowly (§6c.4) |
| Ownership rate | **falls** | foreclosed households return to the rental market and are credit-locked for five years |

The foreclosure prediction is the one this project has already said, in writing and before the
run, that it expects to **miss low**: phase C measured deliveries at ≈0.02%/yr in a calm
baseline against 0.10–0.16% observed, because distressed owners with positive equity sell
first (`docs/validation.md`, phase C). Phase D added the mechanism that should close it in a
bust — negative equity blocking the sale — and this run is the test of whether it does.

## Reporting category claimed

**Direction only**, for every quantity above. The variance rule (`model-spec.md §13.2`) is
applied on the phase-E Sobol run, not here, and a hold-out is evidence about the
specification rather than a forecast. Magnitudes are reported as measured and compared with
the observed bands, but no magnitude from this run is claimed as a prediction.
