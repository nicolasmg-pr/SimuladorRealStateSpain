# docs/

Small, scoped reference files for this project. Precision, not volume.

Belongs here:
- The model spec: actors, tick order, price mechanism, parameter meanings and units
- Real market data we calibrate against, with source URL and date
- Literature notes: which paper a behavioural rule comes from
- API documentation pasted from services we integrate
- Our data structures: field names, value types, units

Does not belong:
- General tutorials the agent already knows
- Python or Streamlit installation guides
- Task lists or feature ideas
- Screenshots or binary files
- Secrets. Never.

Each file: one topic. If pasted from the web, include source URL and date.
